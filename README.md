# My beloved master's thesis
Hey! Here you can find the code & data for my thesis on the topic of representation of femicides in the German media. 
# Self-explanatory navigation
**GE_group.csv and ME.group.csv**. Two data files that consist news articles featuring the German perpetrators and the perpetrators of the Middle Eastern origin. I compare these two groups to analyse the differences in reporting and if there is any othering for the Middle Eastern cases (spoiler: there is).

**datafinal.R**. My final code that includes data preprocessing and analysis.
# Method
In my thesis I use quantitative text analysis. Namely, I apply structural topic modeling, named entity recognition nd GloVe model but also some other cool and simpler things.
